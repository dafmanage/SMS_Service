SMS Configuration

Configure SMS provider settings and parameters

Provider name is required and must be at least 2 characters
Valid API URL is required (must start with http:// or https://)
API key is required and must be at least 10 characters
API secret is required and must be at least 10 characters
Sender ID is required and must be at least 3 characters
Message length must be between 1 and 1600 characters
Daily message limit must be at least 1
Cost per message must be at least 0.01 ETB
Retry attempts must be between 1 and 5
Retry delay must be between 10 and 300 seconds
Please enter a valid phone number
